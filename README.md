# 🏥 Pappolo Healthcare Inventory Management Dashboard

## 📌 Project Overview
The **Pappolo Healthcare Inventory Management Dashboard** is a data analytics project developed using **Microsoft Power BI and Excel** to monitor healthcare inventory, track medical stock levels, and improve inventory management operations.

The dashboard provides meaningful insights into inventory availability and helps identify stock-related trends to support better decision-making.

## 🎯 Project Objectives
- Monitor medical inventory and stock availability.
- Track inventory levels across different categories.
- Identify potential stock shortages and inventory issues.
- Analyze inventory data for better operational planning.
- Support data-driven inventory management decisions.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and data visualization.
- **Microsoft Excel** – Data cleaning, preparation, and analysis.
- **Power Query** – Data transformation and preprocessing.

## 📊 Key Features
- Interactive inventory dashboard.
- Medical stock level monitoring.
- Inventory analysis and reporting.
- Visual representation of healthcare inventory data.
- Easy-to-understand KPIs and charts.


## 💡 Key Learnings
- Working with healthcare inventory datasets.
- Data cleaning and transformation using Power Query.
- Building interactive dashboards in Power BI.
- Creating meaningful visualizations for business insights.
- Understanding inventory management analytics.
